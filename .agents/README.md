# README for antigravity harness 



## Goal
- have trust in agents, no strict workflows and too strict guiding for agents, the agent should figure out a way itself, we won't use specialized predefined subagents the agent should decide itself which subagents to create
- provide skills that enable automatically whenever the agent needs more knowledge in a specific domain he is currently operating in (e.g. when he is implementing code a skill describes how the code should look like, when he is architecting specs a skill specialised on this etc.), at best no manual skill activation. (I am okay with copying some skills directly from the ECC repo)
- tight linting and left hook checking (mostly implemented)
- have some form of an advanced memory system, where the agent can write in things and read stuff, to prevent doing same decisions over and over again, and that you are just talking to an expert in your project when you talk to the agent, this system should be autonomous (every agent will write in there or read from it)
- install mgrep (it is potentially be a lot better than grep)
- use some useful mcp servers (but use them sparsely)
- fill GEMINI.md at different levels of the project
