---
name: implement-issue
description: Use when a given issue name or number needs to get implemented
---
- you get an issue number or an issue name and should implement it
- use make get-issue <Number> to get the correct issue definition
- implement the code as stated into issue, no creativity
- the tests for the given issue are already implemented use them as guidance
- implement the simplest most boring implementation
- don't overcomplicate code
- follow clean code principles
- you are finished when your code is clean and you pass all tests
- run make commit after implementing all code to save the work, when you get errors fix them and run make commit again
