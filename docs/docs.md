# DOCS
An overview of the documentation for the AI Learning Support project and its implementation process.

## Goal of the project
The goal is to build an learning support system based on llms. It should teach the user any content he wants to learn in an optimal way based on science backed learning strategies and personal prefences. The user uploads the materials he wants to learn and some benchmark exercises, for example past exams and the system acts as a "perfect" teacher who creates an optimal learning plan, is an absolute expert in the content and uses best learning strategies to teach the user. The goal is not to use llms to cheat in the educational realm but leverage its capabilities.


## Documentation structure
- [docs.md](docs.md): This file, an overview of the documentation.
- [tutoring.md](tutoring.md): This file contains the documentation for the tutoring sessions, how they are created and executed.
- [learning_plan.md](learning_plan.md): This file contains the documentation for the learning plan, how it is created and updated.
