# Documentation Standards

- **Code Comments**: 
  - Use JSDoc (`/** ... */`) for all exported classes, functions, types, and interfaces.
  - Inline comments should explain *why* the code does something, not *what* it is doing. The code itself should be readable enough to explain the *what*.
- **README Updates**: If a new significant feature or package is added, ensure the relevant `README.md` is updated.
- **Changelog**: Use Changesets for versioning and changelog generation when appropriate.
