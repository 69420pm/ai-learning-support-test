# Styling Guidelines (Web)

- **Methodology**: Use Vanilla CSS or standard modern CSS approaches. If Tailwind is needed, verify with the user first.
- **Design System**: Use predefined CSS variables and design tokens for colors, spacing, and typography to maintain consistency.
- **Accessibility**: Ensure basic accessibility (WCAG AA) — use semantic HTML, proper contrast, and aria attributes where interactive elements lack native roles.
- **Responsive Design**: Mobile-first approach using standard breakpoints.
